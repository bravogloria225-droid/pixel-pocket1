GAME LIBRARY

Load game files from your iPhone (Files app). Use games you own or free homebrew.

SUPPORTED

  • GB / GBC .gb .gbc
  • GBA .gba
  • NES .nes
  • SNES .sfc .smc
  • GENESIS .md .gen .smd .bin
  • PS1 .chd .pbp .iso .bin (single file)
  • .zip / .7z you'll pick the system

PS1 tip: one-file formats (.chd or .pbp) work best. Multi-file .cue + .bin sets won't load.

AD BLOCK SETUP

iPhones only let ad blockers run inside Safari or at the network level. A home-screen app can't do it. Do this once and it covers Safari everywhere:

  1. Install AdGuard (free) from the App Store.
  2. Open it and turn protection on.
  3. Go to Settings → Apps → Safari → Extensions. Turn on every AdGuard item.
  4. Done. Links below open in Safari with ads blocked.
BLOCK ADS IN EVERY APP (optional)
  1. Make a free account at nextdns.io.
  2. In Privacy, add the "AdGuard DNS filter" blocklist.
  3. In Setup, choose iOS and install the profile it gives you.
  4. Approve it in Settings → General → VPN & Device Management.

No blocker catches 100% of ads, and some sites stop working when they detect one.
